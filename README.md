# CodeRSA: Reproducible Implementation and Verification Package

This repository provides a fully self-contained reproducibility package for **CodeRSA**,  
a reasoning-aware evaluation framework for analyzing and verifying code generation from large language models (LLMs).  
It contains verified data, pipeline scripts, and baseline comparisons for anonymous academic review.

## ⚙️ Environment Setup

Python ≥3.10 is required.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r env/requirements.txt
```

Optional (for LLM-based generation and Coder–Reviewer scoring):
```bash
pip install vllm transformers datasets
```

## 🧪 Reproduction Pipeline

The CodeRSA experiment can be reproduced through the following stages:

### 1️⃣ Code Generation (optional, GPU required)
```bash
python scripts/pipeline/generate_llama3.py   --dataset mbpp   --model meta-llama/Meta-Llama-3-8B-Instruct   --n 10   --out data/mbpp_llama3_8b_output.json
```

### 2️⃣ Unit Testing
```bash
python scripts/pipeline/test_candidates.py   --infile data/mbpp_llama3_8b_output.json   --outfile data/mbpp_llama3_8b_tested.json
```

### 3️⃣ Coder–Reviewer Scoring
```bash
python scripts/pipeline/coder_reviewer.py   --infile data/mbpp_llama3_8b_tested.json   --outfile data/mbpp_llama3_8b_cr.json   --model meta-llama/Meta-Llama-3-8B-Instruct
```

### 4️⃣ RSA-with-Tokens Evaluation
Using the included verified dataset:
```bash
python scripts/verify_rsa_with_tokens.py --file data/rsa_mbpp_llama3_8b.json --A 1.0
```
Expected output (reproduced from included data):
```json
{"strict_accuracy": 0.595, "mean_accuracy": 0.646, "total": 257}
```
which corresponds to **59.5% strict accuracy**, matching the reported CodeRSA result.

Baseline comparison (approximate references):
- CodeRSA (without clustering): 47.9%
- Coder: 53.3%
- Coder–Reviewer: 56.4%
